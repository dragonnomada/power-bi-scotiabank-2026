## Temario

### Módulo I - Fundamentos de Power BI y flujo analítico

1. Arquitectura básica: Desktop, Service y Gateway.
2. Flujo de trabajo: fuente -> transformación -> modelo -> reporte -> publicación.
3. Estructura recomendada de un proyecto de BI.
4. Errores comunes de implementación.
5. Caso base del curso.

### Módulo II - Power Query y calidad de datos

1. Conexión a fuentes (Excel, CSV, SQL y otras).
2. Tipos de datos y transformaciones esenciales.
3. Limpieza y estandarización de datos.
4. Consultas reutilizables y trazabilidad.
5. Validaciones básicas de calidad de datos.

### Módulo III - Modelado relacional y modelo estrella

1. Tablas de hechos y dimensiones.
2. Claves, cardinalidad y relaciones.
3. Tabla calendario e inteligencia de tiempo base.
4. Buenas prácticas de diseño de modelo.
5. Diagnóstico de errores de relación.

### Módulo IV - Visualización y storytelling ejecutivo

1. Selección de visual según objetivo de negocio.
2. Diseño de páginas ejecutivas y operativas.
3. Segmentadores, filtros y navegación.
4. Jerarquías, desgloses e interacción visual.
5. Estándares de claridad y consistencia visual.

### Módulo V - DAX aplicado a KPIs de negocio

1. Medidas vs columnas calculadas.
2. Cálculos de acumulados y variaciones.
3. KPIs de seguimiento (YoY, MoM, YTD).
4. Contexto de filtro y contexto de fila.
5. Patrones de medidas para tableros de control.
   
### Módulo VI - Publicación, seguridad y operación en Power BI Service

1. Publicación y organización en espacios de trabajo.
2. Configuración de actualización programada.
3. Compartición y consumo de reportes.
4. Seguridad por roles (RLS introductorio).
5. Buenas prácticas de gobierno y versionado.

### Módulo VII - Rendimiento y optimización de reportes

1. Buenas prácticas para modelos de alto volumen.
2. Optimización de medidas y visualizaciones.
3. Identificación de cuellos de botella.
4. Estrategias de mejora incremental.
5. Checklist técnico de performance.

### Módulo VIII - Rutas de profundización (Tronco + Rutas)

1. Ruta A (Negocio): tableros accionables y adopción por área.
2. Ruta B (Modelado/DAX): métricas dinámicas y optimización avanzada.
3. Ruta C (Integración): SQL/Python en escenarios aplicados.
4. Ejercicio integrador por ruta.
5. Cierre con proyecto breve y plan de mejora 30/60/90.
