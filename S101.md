## Resumen

En esta clase se comparó el análisis tradicional de Excel con Power BI.

En Excel un uso común es usar las hojas de cálculo como repositorios o bases de datos, sin embargo, estas suelen estar desorganizadas y mantener la fusionados los datos de análisis y los reportes o tableros de información (alto acoplamiento).

Una mejor estrategia dentro de Excel es separar los datos en una hoja independiente y estructurarlos como tabla, para que en otras hojas de cálculo se realice el análisis de forma separada.

También, se pueden construir reportes mediante fórmulas, para concentrar información derivada de los datos mediante cálculos como conteos, sumas y promedios.

Estos reportes manuales se pueden visualizar mediante gráficas que seleccionen las series de datos y se configuren manualmente.

Las tablas dinámicas de Excel nos permiten evitar fórmulas complicadas para poder diseñar análisis largos y anchos para obtener fácilmente agregaciones marginales como sumas y promedios.

Finalmente, usando gráficos dinámicos se puede interactuar con la tabla dinámica y los gráficos.

Para alcanzar una mejor abstracción de análisis en Excel, es mejor dejar los datos en libros indepedientes a sus reportes y análisis, y mediante Power Query conectar los orígenes de datos desde los libros u otras fuentes.

Power Query nos permitirá limpiar y transformar los datos, para que los reportes sean una consecuencia directa de los modelos construidos mediante consultas y flujos de operaciones de transformación.

En Power BI, partimos nativamente del sistema de Power Query, el cual nos permite crear un flujo "end-to-end" de: 

> Fuente -> Transformación -> Modelo -> Reporte -> Publicación 

Dentro de Power BI, cada modelo adquirido en Power Query será traducido a un **Modelo Semántico** que podremos utilizar dentro de los informes.

Los informes son libretas compuestos de páginas que usarán objetos visuales conectados a los modelos semánticos para visualizar los datos de manera efectiva, por ejemplo, mediante tablas, barras de columnas combinadas, medidores o mapas.

Cada objeto visual se puede configurar arrastrando y soltando los ejes de análisis y agregando los valores (recuento, suma, promedio, etc.).
