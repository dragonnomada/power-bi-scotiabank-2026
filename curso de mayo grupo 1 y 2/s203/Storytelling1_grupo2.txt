Ventas = CONTAR FILAS folio
Plazo Promedio = PROMEDIO plazos
Dias Promedio Recuperacion = [Plazo Promedio] * 7
Pagos Promedio = PROMEDIO pagos
% Avance = DIVIDE pagos / (plazos + 1)
Monto Inversion = SUMA precio
Monto Recuperacion Inicial = SUMA anticipo
Monto En Riesgo = [Monto Inversion] - [Monto Recuperacion Inicial]
Monto Total = SUMA total
Monto Margen = [Monto Total] - [Monto Inversion]
Monto Esperado = SUMA montoTotalEsperado
Monto Recibido = SUMA montoTotalRecibido
Monto Faltante Absoluto = SUMA montoTotalFaltanteAbsoluto
Monto Faltante Relativo = SUMA montoTotalFaltanteRelativo
% Progreso Absoluto = DIVIDE [Monto Recibido] / [Monto Total]
% Progreso Relativo = DIVIDE [Monto Recibido] / [Monto Esperado]
% Progreso Esperado = DIVIDE [Monto Esperado] / [Monto Total]
% Atrasado = [% Progreso Esperado] - [% Progreso Absoluto]
% Progreso Faltante Absoluto = DIVIDE [Monto Faltante Absoluto] / [Monto Esperado]
% Progreso Faltante Relativo = DIVIDE [Monto Faltante Relativo] / [Monto Esperado]
% Avance Dias Activos = DIVIDE diasActivos / diasTotales
% Avance Dias Transcurridos = DIVIDE diasTranscurridos / diasTotales
Retraso Dias = SUMA diasTranscurridos - SUMA diasActivos
% Retraso Dias = [% Avance Dias Transcurridos] - [% Avance Dias Activos]
% Retraso Absoluto = DIVIDE [Retraso Dias] / diasTotales
Dias Promedio Activo = PROMEDIO diasActivos
% Avance Activo Promedio = PROMEDIO diasActivos / diasTotales
% Avance Transcurridos Promedio = PROMEDIO diasTranscurridos / diasTotales
% Retraso Promedio = [% Avance Transcurridos Promedio] - [% Avance Activo Promedio]
