## Resumen

En esta clase se profundizó en el uso de Power Query y el *lenguaje M* para el diseño de una tabla de hechos partiendo del caso de estudio de la financiera.

Mediante transformaciones, combinaciones, agrupaciones y código se iteraron diferentes etapas de la tabla de amortización para alcanzar una tabla de hechos que sea más fina y permita mostrar la información de las fechas esperadas de pago, los montos esperados, así como dejar todo listo para tener la tabla completa de las fechas y los montos de pagos recibidos, y con esto poder contrastar la información del progreso de los pagos, para poder determinar un progreso real de los pagos, y así poder establecer indicadores KPI importantes para los reportes.

La pieza de código más importante se construyó mediante una agrupación dinámica que de no ser indexada producirá un tiempo excesivo de cómputo, por lo que dentro de la agrupación debemos indexar la tabla previa al cálculo de la mínima fecha de pago esperada, para así poder construir las demás fechas esperadas en los siguientes pagos:

> Calcular los montos acumulados para cada plazo

```m
let
    Origen = #"amortizacion 4",
    #"Paso 1" = Table.Group(
        Origen, 
        {"folio"}, 
        {
            {
                "Montos Esperados Acumulados", 
                each 
                    let 
                    OrigenIndexado = Table.AddIndexColumn(
                        _,
                        "indice",
                        0,
                        1,
                        Int64.Type
                    ),
                    Acumulados = Table.AddColumn(
                        OrigenIndexado,
                        "montoEsperadoAcumulado",
                        each
                            List.Sum(
                                List.FirstN(OrigenIndexado[montoEsperado], [indice] + 1)
                            )
                    ) in Acumulados
            }
        }
    ),
    #"Se expandió Montos Esperados Acumulados" = Table.ExpandTableColumn(#"Paso 1", "Montos Esperados Acumulados", {"numero", "fechaEsperada", "montoEsperado", "montoEsperadoAcumulado"}, {"numero", "fechaEsperada", "montoEsperado", "montoEsperadoAcumulado"})
```
