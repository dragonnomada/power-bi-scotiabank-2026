## Resumen

En esta clase se continua con el manejo del *Lenguaje M* y *DAX*.

El proceso fundamental para poder indexar grupos está dado por un paso adicional que debemos colocar en el script de pasos, y así determinar para cada grupo el índice adecuado comenzando por 0 y continuando de 1 en uno de ser así lo que requerimos.

Esto nos permitirá reconstruir por fecha un orden temporal y secuencial en cada grupo y poder llegar a tablas de hechos que exploten esta información.

> Agregar un paso para agrupar filas

```dax
#"Tabla agrupada e indexada" = Table.Group(
  #"Filas ordenadas1",
  {"folio"},
  {
    {
      "pagos",
      each Table.AddIndexColumn(
      	_, 
      	"numeroPago", 
      	0, 1, 
      	Int64.Type
      )
    }
  }
),
```
