## Resumen

En esta clase se estudió la construcción de un *Storytelling* para narrar un objetivo de análisis.

PowerQuery (Origen) -> Power BI (Modelo Semántico)

### Modelo Estrella

- **Tablas de Hechos**: Un análisis por cada hecho
- **Tablas de Dimensiones**: Extensiones a los hechos

### Modelo Relacional

**Clave**: ¿Quién se relaciona?

**Tipo de relación**: 	

	(1-*) Uno a Muchos (Grueso - Fino)
	(*-1) Muchos a uno (Fino - Grueso)

### Storytelling

Esclarece la narrativa de hechos para producir informes.

> Pasos de construcción de la narrativa

1. Establecer un objetivo de anális (hecho / reporte)
2. Concentrar todos hechos que explican el objetivo
3. Creamos las medidas que explican el objetivo
	- La linea de tendencia (linea de tiempo / linea operación)
	- Métrica de Observación: 

			Valor (Actual / Observado)
			Meta (Esperado / Objetivo)
		
4. Integramos un reporte usando la tabla de hechos, el valor y la meta (métricas) explicadas en la línea de tendencia
5. Representamos el reporte a tráves de informes gráficos/tabulares o alternativos

> Preguntas clave para la construcción de la narrativa

1. ¿Cuál es el objetivo del análisis?
2. ¿Qué hechos explican el objetivo?
3. ¿Qué indicador será observado para explicar el objetivo?
4. ¿Cuál es la línea de tendencia del indicador?
	- ¿Quién explica el indicador?
	- ¿A través de quién observamos el indicador?
5. ¿Cómo cambia el indicador a través de la línea de tendencia?
	- ¿Podemos observar el cambio del indicador Mes a Mes / Año por Año?
	- ¿Podemos observar el cambio del indicador acumulado a una fecha?
	- ¿Podemos ordenar la tendencia través de un indicador?

### Ejemplo de la narrativa

Podemos crear un *Storytelling* con el objetivo de analizar cuántos pagos han sido cubiertos de los esperados.

**Objetivo**: Pago Cubierto / Pago Esperado

> Pago Cubierto:

	fechaPagoRecibido
		- (VACÍO): No pagado
		- Fecha: Pagado
	pagoMontoRecibido
	pagoCubierto
		if [fechaPagoRecibido] = null then 0 else [pagoMontoRecibido]

> Pago Esperado:
	
	fechaEsperaPago
		1. # de Pago
		2. fechaAnticipo + # de Pago semanas
	montoEsperado
		1. Si # de Pago es 0: El valor del anticipo
		2. Sino: El valor semanal
	pagoEsperado
		1. Si fechaEsperaPago es mayor a hoy: 0
		2. Sino: montoEsperado

> Indicador:

	% Recuperación: Suma(Pago Cubierto) / Suma(Pago Esperado)
	% Mora: 1 - % Avance
	% Avance Pagos: Suma(Pagado) / Recuento(Pago Esperado)

> Línea de Tendencia: `fecheEsperadaPago`

	- Mes a Mes (MoM) / Año con Año (YoY) / Periodo a la Fecha (YTD)

> Tabla esperada

FECHA ESPERADA | % Recuperación | Pago Cubierto | Pago Esperado | Fecha Recibido | Monto Recibo | Fecha Esperada | Monto Esperado | # de Pago | Folio
